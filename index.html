Structure

The single entry point is prompts/index.md. Hard points (hard_points) are authoritative, followed by the Truth Tables (gen). 

prompts/
├── index.md            # single entry point
├── hard_points/        # immutable truths (absolute priority)
│   ├── agents/  commands/  system/  ...
└── gen/                # project Truth Tables
    ├── concepts/   techniques/
    ├── agents/     personas/
    └── use_cases/

Internal agents

agent-aikido-* agents are tools, agents and modes at the same time. They automate the maintenance of the Memory Bank.

Explore Bank / Code / All

Search the documentation, the code, or both in parallel.

Truth Evaluator

Determines the authoritative source when sources conflict.

Validator & Doc Header

Checks file compliance and manages document headers.

Balancer & Index

Rebalances the tree and keeps indexes up to date.

Bank Populate & RACI Delegator

Fills the gaps and classifies new documents.

Fusion & Update Controller

Updates AI-KIDO while preserving the project's local context.

Get started

Install AI-KIDO in your project or update an existing base.

# Initialize AI-KIDO in the project
/init-aikido

# Update an existing base
/maj-aikido --update

# Compliance audit
/analyse-aikido
