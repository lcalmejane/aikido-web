Local Designer · A skill for the AI-KIDO method

Validate the look first.
Then generate the images.

Local Designer gives your agents an art director. It turns a brief into a mood board, waits for your validation, then renders images locally in the identity you chose.

Install the skill See what it does Browse the styles

Skill version 5.3.0 · Renders on your machine with Draw Things · Charter, mood boards and UI kit live in one folder you can version with your project

Don't let an agent improvise your visual identity.

Without a direction, every generated image looks different. Local Designer puts a validation step before the first render and keeps the decision, so the whole project speaks with one visual voice.

Before drawing

Start from a brief

A structured brief captures the message, audience, uses, palette, fonts and what to avoid. The skill can also read an existing project folder to propose a starting point.

Before generating

A lock until you validate

Generation refuses to run until a direction is validated on the mood board or the design charter is active. The decision and the validator's name are recorded.

After rendering

Every image is read

The image analyst checks each result for defects, text and likeness before you see it. It uses a local vision model if you set one, otherwise your current model.

From brief to final render

Four building blocks, each usable on its own and all stored in one design folder of your project.

Mood board

Compare directions in situation

Three directions are shown on the same scenes, each with its palette and roles, typography, textures, what it says and what it rules out. One self-contained page, light and dark, ready to send to the client. Command: /aikido-design-moodboard.

Design charter

A durable identity

Palette with roles, typography, validated render style, forbidden terms and a dated decision log, in a text file safe to commit. An audit measures the colour drift of any image against the palette. Commands: /aikido-init-design, /aikido-design-audit.

UI kit

An interface vocabulary

Five personalities compared on one page with your colours. Once you choose, the skill builds light and dark tokens checked for contrast (4.5:1 for text), components, icons, button images and zone backgrounds. No image engine needed. Command: /aikido-design-uikit.

Render

Draft, tune, finalize

Start with quick drafts, compare styles on a contact sheet kept outside git, then render the final image behind the lock. Seed and prompt are saved so any image can be reproduced. Commands: /aikido-design-render, /aikido-design-style.

29 render styles, each with its own thumbnail

Photographic, vector, drawn, painted, technical or editorial. Pick one, let the skill recommend one from your brief, blend two into a new look, or draft a style from a reference image.

Style tools: recommend, analyze, match, styles compose and styles draft. These thumbnails are the skill's own, rendered with Draw Things.

Two agents, two roles

Agent

Art director

agent-aikido-art-director

A senior illustrator: it asks the right questions, proposes directions, builds the mood board, waits for the client's answer, then draws and tunes.

Agent

Image analyst

agent-aikido-image-analyst

It reads every image: defects, text, pose, likeness to a reference. It uses the optional local vision model of the project, otherwise the current model, silently. A reader can still miss defects: “ok” means nothing was found.

Eight commands for your assistant

Type them in your assistant once the skill is installed.

CommandWhat it does
/aikido-init-designCreate the project design charter: palette, typography, render style.
/aikido-design-briefWrite and validate the structured client brief.
/aikido-design-moodboardBuild the client mood board and record the client's decision.
/aikido-design-styleChoose, compare, compose and create render styles.
/aikido-design-uikitCreate and maintain the UI kit: tokens, components, icons, button and zone images.
/aikido-design-renderGenerate images: draft, tuning sweeps, final render behind the validation lock.
/aikido-design-charterRead, check, update and annotate the charter; generate under its identity.
/aikido-design-auditCheck images or a folder against the charter palette and report the drift.

Runs on your machine

Images are generated by a connector, the engine installed on your Mac. Two connectors are available, both for the Draw Things app.

Draw Things, over HTTP or gRPC

Use the app's HTTP API, or gRPC, which lists the real models of the server and can reach a local, remote or offload server of your own.

Local first

Local mode is the verified path. Sending anything outside your machine requires your agreement.

Honest limits

Image models sometimes ignore instructions: text, hands and faces need a check. One image is generated at a time, and ComfyUI is planned, not written.

The brief, the mood board (without trial renders), style browsing, the UI kit and image analysis need no image engine.

Install and start

The skill is installed with the AI-KIDO skills manager. Requirements: Node.js 18 or later, cwebp for WebP export, ImageMagick or sips for image analysis, and for generation macOS with Draw Things.

  1. Enable the API server

    In Draw Things, open the advanced settings and enable API Server: gRPC on port 7859 (recommended) or HTTP on port 7860. Keep the app open.

  2. Check the engine

    Run status to see the model and settings in use, and whether the target is local or remote.

  3. Brief, validate, render

    Write the brief, validate a direction on the mood board, then ask for your first image.
