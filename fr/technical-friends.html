Sites amis techniques

Les bons outils se nourrissent d’un écosystème vivant. Voici les projets que nous utilisons, les assistants que nous ciblons et les idées qui inspirent nos composants.

Une sélection de références techniques, pas une liste de partenaires commerciaux. Ces liens n’impliquent ni affiliation, ni sponsoring, ni approbation officielle. Chaque projet conserve son identité et sa licence.

Outils et fondations

Du code partagé à la génération locale d’images : les briques qui entourent la méthode et ses outils.

GitHub

Les dépôts, la collaboration et les versions de la méthode et de ses outils publics. GitHub Pages héberge ce site.

Draw Things

Le moteur d’images local relié à Local Designer en HTTP ou gRPC, utilisé pour créer les illustrations du site.

Model Context Protocol

Le protocole par lequel Kimono RAG MCP expose ses outils de recherche de connaissances aux assistants compatibles.

Kimono RAG MCP

Notre composant de recherche de connaissances : sélectionner les sources pertinentes d’un projet et les transmettre à un assistant via MCP.

Node.js

Le moteur JavaScript des outils de distribution, des scripts de Local Designer et du serveur MCP de Kimono RAG MCP.

Docker

Les outils de conteneurisation de l’environnement Tatami et du serveur MCP partagé de Kimono RAG MCP.

Visual Studio Code

Un environnement d’édition pour les intégrations Copilot et l’extension Kimono RAG MCP.

RTK

Un proxy en ligne de commande écrit en Rust qui compresse la sortie du shell avant qu’elle n’atteigne le modèle. L’environnement Tatami l’embarque et l’active pour les assistants capables de réécrire les commandes.

Les amis techniques au cœur de Kimono RAG MCP

La recherche locale s’appuie sur des projets open source spécialisés. Ce sont des briques d’implémentation, pas des services de recherche distants : la politique d’embedding choisie détermine les modèles et moteurs utilisés.

fast-grep

fast-grep

Le moteur natif de recherche lexicale indexée, pour retrouver efficacement les passages pertinents dans le texte et le code.

embsearch

embsearch-core

La bibliothèque Rust de recherche sémantique utilisée par le moteur natif de Kimono RAG MCP, avec prise en charge des embeddings ONNX.

ONNX Runtime

Exécute le modèle d’embedding E5 localement. Kimono RAG MCP mesure les moteurs d’exécution disponibles pour les départager ; les modèles statiques n’ont pas besoin d’ONNX.

MinishLab · Model2Vec et Potion

Des embeddings statiques pour le code et la recherche multilingue rapide : les modèles Potion code et multilingue utilisent des tables de tokens locales, sans inférence de transformer.

Hugging Face

Le catalogue qui héberge les fichiers de modèles épinglés et leurs fiches. Les téléchargements demandent confirmation ; l’indexation et la recherche restent locales.

E5

Multilingual E5 small

Le modèle d’embedding multilingue de la politique E5, distribué dans sa version ONNX quantifiée par Xenova sur Hugging Face.

Rust

Le langage des composants natifs de recherche et d’embedding de Kimono RAG MCP, aux côtés du serveur MCP en TypeScript.

Tree-sitter

Les analyseurs de langages utilisés par le moteur sémantique pour comprendre la structure du code lors de la préparation des fragments.

Assistants et CLI cibles

AI-KIDO adapte ses instructions, skills et agents aux différents hôtes. Ce sont des cibles de distribution, pas une promesse de fonctions identiques ou de validation sur chaque hôte.

Claude Code

L’assistant de développement d’Anthropic, avec une distribution adaptée à ses instructions, commandes, skills et agents.

GitHub Copilot

L’assistance IA sur GitHub et dans VS Code ; son CLI propose également un usage depuis le terminal.

GitHub Copilot CLI

Le workflow Copilot dans le terminal, également utilisé pour mesurer les gains de recherche de contexte de Kimono RAG MCP.

Codex

L’agent de développement d’OpenAI, ciblé via les instructions du projet, les skills du workspace et les agents personnalisés.

Kiro CLI

Un assistant en terminal avec une distribution AI-KIDO dédiée aux skills et agents du workspace.

Zoo-Code

Une cible de distribution pour les workflows par modes et une source d’idées d’interaction pour l’interface agent de Tatami.

Roo Code

La cible de distribution historique pour les instructions, modes et commandes au format Roo.

Google Antigravity

Une cible de distribution utilisant les instructions de projet, les skills et les définitions d’agents.

Les formats d’installation et les conditions propres à chaque hôte sont détaillés dans le guide AI-KIDO accessible depuis la page Installer.

Inspirations open source

Des projets qui ont nourri l’interface agent de Tatami. Inspiration et adaptation ne signifient ni reprise de toutes les fonctions, ni utilisation de tous les moteurs d’exécution d’origine.

OpenGUI

Une référence d’origine pour l’espace de travail agent et l’interface conversationnelle adaptés dans Tatami.

OpenIntelligentUI

Une référence pour les interfaces génératives et les aperçus interactifs isolés à côté de la conversation.

CopilotKit

L’écosystème open source d’interfaces pour agents derrière OpenIntelligentUI, pour explorer les idées d’UI générative.
