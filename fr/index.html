Une Memory Bank pensée pour les LLM

AI-KIDO est une méthode structurée pour créer et maintenir une base de connaissances hiérarchique, lisible par les humains et exploitable efficacement par les assistants IA.

Structure

Le point d'entrée unique est prompts/index.md. Les points durs (hard_points) font autorité, puis viennent les Truth Tables (gen). 

prompts/
├── index.md            # point d'entrée unique
├── hard_points/        # vérités immuables (priorité absolue)
│   ├── agents/  commands/  system/  ...
└── gen/                # Truth Tables du projet
    ├── concepts/   techniques/
    ├── agents/     personas/
    └── use_cases/

Agents internes

Les agents agent-aikido-* sont à la fois des outils, des agents et des modes. Ils automatisent la maintenance de la Memory Bank.

Explore Bank / Code / All

Recherche dans la documentation, dans le code, ou les deux en parallèle.

Truth Evaluator

Détermine la source faisant autorité en cas de conflit.

Validator & Doc Header

Vérifie la conformité des fichiers et gère leurs en-têtes.

Balancer & Index

Rééquilibre l'arbre et maintient les index à jour.

Bank Populate & RACI Delegator

Comble les manques et classe les nouveaux documents.

Fusion & Update Controller

Met à jour AI-KIDO en préservant le contexte local du projet.

Démarrer

Installez AI-KIDO dans votre projet ou mettez à jour une base existante.

# Initialiser AI-KIDO dans le projet
/init-aikido

# Mettre à jour une base existante
/maj-aikido --update

# Audit de conformité
/analyse-aikido
