AI-KIDO · Distributions and installation

One knowledge base. Every assistant. Installed in minutes.

The AI-KIDO Memory Bank, its commands, skills and agents are packaged for nine assistants. Pick yours, review what will be written to your project, apply it, then build your own Memory Bank.

Choose your assistant What is included How to install

What the knowledge base gives you

The same content is delivered to every assistant, adapted to the format it understands.

22 commands

Initialize the Memory Bank, analyse a project, check documentation against the code, create personas, commands and skills, manage installable skills, and more.

15 specialized agents

Truth evaluator, RACI delegator, validator, explorers, balancer, index maintenance and an orchestrator that adapts to your assistant's native one.

6 system skills

Project analysis, Memory Bank updates, orchestration, code and knowledge search, structure rules and web page download.

Hard points

Immutable rules and techniques that keep the Memory Bank structured, traceable and under the size limits that keep it efficient for an LLM.

Reviewable setup

Nothing is written silently: a plan lists every file, you apply it with a confirmation, and existing project customizations are shown for review.

Updates and removal

Update the method in a project, migrate an existing one, or remove the integration while keeping your project knowledge.

Nine distributions

Each package is generated from the same source and published under an immutable release tag.

Plugin-based hosts (Claude Code, Claude Cowork, VS Code) install once for your account or editor. Workspace-based hosts (Copilot coding agent, Codex, Kiro, Zoo, Roo, Antigravity) write reviewed files into each project.

Install in three steps

1

Get the package

Clone the release tag and pick the directory of your assistant.

2

Review the plan

Choose STANDARD, LIGHT or UNSET as the entry point and preview the files to install.

3

Apply and initialize

Apply with the plan ID, then run /init-aikido in your assistant to start your Memory Bank.

# 1. Get the package
git clone --depth 1 --branch aikido-dist-v1.5.1 \
  https://github.com/lcalmejane/aikido.git aikido-dist

# 2. Preview what will be installed in your project
node aikido-dist/<package>/scripts/bootstrap-plan.mjs \
  --root /path/to/project --package aikido-dist/<package> --mode STANDARD

# 3. Apply the reviewed plan
node aikido-dist/<package>/scripts/bootstrap-plan.mjs \
  --root /path/to/project --package aikido-dist/<package> --mode STANDARD \
  --apply --confirm <plan-id>

Claude Code installs from a pinned marketplace instead:

claude plugin marketplace add \
  https://github.com/lcalmejane/aikido.git#aikido-dist-v1.5.1
claude plugin install aikido@aikido

Claude Cowork: zip the claude-cowork package and upload it in Customize > Plugins > Add > Upload plugin.

Update or remove

Installing a newer plugin and updating the method in a project are separate actions. Run the new package's update-plan.mjs against your project, review the plan, then apply it. Add --migrate for a project that has no AI-KIDO lock yet, or --uninstall to remove the integration files. Your project's Memory Bank always stays.

Extend it with installable skills

Beyond the built-in content, /skill-manage searches, installs, updates and removes skills from a catalog and from trusted external sources.

Safe by design

A deterministic engine validates names and sources, refuses symbolic links, never runs a skill's scripts and keeps a backup of anything it replaces.

Third parties need your approval

External skills are listed with their files and scripts, and installed only after your explicit confirmation.

Your own skills

Create skills with /create-skill and share them through a catalog repository your team controls.
