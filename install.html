Install in three steps

1

Get the package

Clone the release tag and pick the directory of your assistant.

2

Review the plan

Choose STANDARD, LIGHT or UNSET as the entry point and preview the files to install.

3

Apply and initialize

Apply with the plan ID, then run /init-aikido in your assistant to start your Memory Bank.

# 1. Get the package
git clone --depth 1 --branch aikido-dist-v1.5.1 \
  https://github.com/lcalmejane/aikido.git aikido-dist

# 2. Preview what will be installed in your project
node aikido-dist/<package>/scripts/bootstrap-plan.mjs \
  --root /path/to/project --package aikido-dist/<package> --mode STANDARD

# 3. Apply the reviewed plan
node aikido-dist/<package>/scripts/bootstrap-plan.mjs \
  --root /path/to/project --package aikido-dist/<package> --mode STANDARD \
  --apply --confirm <plan-id>

Claude Code installs from a pinned marketplace instead:

claude plugin marketplace add \
  https://github.com/lcalmejane/aikido.git#aikido-dist-v1.5.1
claude plugin install aikido@aikido

Claude Cowork: zip the claude-cowork package and upload it in Customize > Plugins > Add > Upload plugin.

Update or remove

Updating the method is done project by project: run the new package's update-plan.mjs, review the plan, apply it. --migrate for a project with no lock, --uninstall to remove the integration. Your Memory Bank always stays.
