Install

Ask an agent for five images without a direction and you get five different looks. Local Designer adds a decision step before the first render and keeps it, so the whole project speaks with one visual voice.

The idea in one picture

The skill turns a brief into a mood board, waits for your validation, then renders images on your machine with Draw Things. The charter, the mood boards and the UI kit live in one design folder that you can version with your project.

From brief to final render

  1. BriefA structured brief captures the message, audience, uses, palette, fonts and what to avoid.
  2. Mood boardThree directions are shown on the same scenes, with palette, typography and what each one rules out.
  3. ValidationGeneration refuses to run until a direction is validated or the charter is active. The decision and the validator’s name are recorded.
  4. RenderQuick drafts first, then a contact sheet kept outside Git, then the final image. Seed and prompt are saved so any image can be reproduced.

What you see at each step

You open the mood board in your browser and the first thing you read is your own brief, summarised: the message, the audience, the uses and the format. Under it comes the direction that was validated, shown on real scenes rather than described in words.

Before that, you had been shown three directions on the same four scenes. You scroll through A, B and C, compare the lighting, the backdrop and the mood, and answer with a letter and a remark such as “A, but fewer shadows”. Nothing is rendered until you do.

Then you choose how the final images are drawn. The skill ships with 29 render styles, each with a thumbnail, so you point at a look instead of describing it: watercolor, flat vector, line art, isometric, riso, technical blueprint.

For the interface, the UI kit comparison page puts five personalities side by side on the same screen and the same brand colours. You look at corners, shadows and density, then decide with one command, uikit decide A. Here the soft variant A is the one kept.

When the mascot is part of the project, you also get a character sheet to keep every image consistent: the same robot seen from the front, three-quarter, side and back.

Every image is read

An image analyst agent checks each result for defects, text and likeness to a reference before you see it. It uses a local vision model if you set one, otherwise your current model. A reader can still miss defects, so “ok” is not a guarantee.

29render styles, each with its own thumbnail

What it does not do

Works without an image engine

  • The brief
  • The mood board, without trial renders
  • Style browsing
  • The UI kit
  • Image analysis

Needs Draw Things on a Mac

  • Draft renders
  • Tuning sweeps
  • The final render
To remember

Local mode is the verified path. Sending anything outside your machine requires your agreement. Image models sometimes ignore instructions, so check text, hands and faces.

Try it

  1. Install the skill with the skills manager: /skill-manage get --skill local-designer.
  2. In Draw Things, enable the API server: gRPC on port 7859 (recommended) or HTTP on port 7860.
  3. Run the status command to see the model in use and whether the target is local or remote.
  4. Write a short brief, compare the three directions, validate one, then ask for your first image.
